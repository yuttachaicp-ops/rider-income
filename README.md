# บันทึกรายรับ ไรเดอร์ (PWA)

แอพบันทึกรายรับ–รายจ่ายงานส่งอาหาร GrabFood / ShopeeFood ทำงานในเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์
ข้อมูลทั้งหมดเก็บใน IndexedDB บนเครื่องผู้ใช้เท่านั้น

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอพทั้งหมด (โครงหน้า + CSS + JS) |
| `manifest.json` | ข้อมูลแอพ ชื่อ ไอคอน สี ทำให้ติดตั้งได้ |
| `sw.js` | Service Worker — แคชไฟล์ให้เปิดได้แม้ไม่มีเน็ต |
| `icon-192.png` `icon-512.png` | ไอคอนแอพ (Android / Chrome) |
| `apple-touch-icon.png` | ไอคอนสำหรับ iPhone / iPad |
| `favicon.png` | ไอคอนบนแท็บเบราว์เซอร์ |

ต้องอยู่ในโฟลเดอร์เดียวกันทั้งหมด

## วิธีขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub — ตั้งเป็น **Public**
2. อัปโหลดไฟล์ทั้ง 6 ไฟล์ไว้ที่ root ของ repo (Add file → Upload files → Commit)
3. ไปที่ **Settings → Pages**
   - Source: `Deploy from a branch`
   - Branch: `main` / โฟลเดอร์ `/ (root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`
5. เปิดลิงก์นั้นบนมือถือ

## วิธีติดตั้งบนมือถือ

**Android (Chrome)** — เปิดลิงก์ → จะมีแถบ “ติดตั้งเป็นแอพบนมือถือ” โผล่ขึ้นด้านบน กดปุ่ม **ติดตั้ง**
ถ้าไม่เห็น: เมนู ⋮ → “ติดตั้งแอป” / “เพิ่มลงในหน้าจอหลัก”

**iPhone (ต้องใช้ Safari)** — เปิดลิงก์ใน Safari → กดปุ่มแชร์ ⤴ ด้านล่าง → เลื่อนหา
**“เพิ่มไปยังหน้าจอโฮม”** → Add
(Chrome บน iPhone ติดตั้งไม่ได้ ต้อง Safari เท่านั้น)

หลังติดตั้งจะเปิดเต็มจอไม่มีแถบเบราว์เซอร์ และใช้งานได้แม้ปิดเน็ตสนิท

## เวลาแก้ไฟล์ (สำคัญ)

เปิด `sw.js` แล้วเปลี่ยนเลข `VERSION` บรรทัดที่ 3 เช่น `v1.2.0` → `v1.2.1` **ทุกครั้ง**ที่แก้ `index.html`
ถ้าไม่เปลี่ยน เครื่องที่ติดตั้งไปแล้วจะยังใช้ของเก่าที่แคชไว้

## การอัปเดตในแอพ

ผู้ใช้ไม่ต้องทำอะไรเป็นพิเศษ แอพจัดการเองทั้งหมด

- ตรวจหาเวอร์ชันใหม่ตอนเปิดแอพ ทุกครั้งที่สลับกลับมาหน้าแอพ และทุก 30 นาทีระหว่างเปิดอยู่
- เจอเวอร์ชันใหม่ → ขึ้นแถบเขียว “มีเวอร์ชันใหม่พร้อมใช้” ค้างไว้ด้านบน (ไม่หายไปเอง)
- กด **อัปเดตเลย** → โหลดเวอร์ชันใหม่ทันที ข้อมูลใน IndexedDB ไม่ถูกลบ
- ตรวจเองได้ที่แท็บ **สรุป → เวอร์ชันแอพ → ตรวจหาอัปเดต** พร้อมดูเลขเวอร์ชันที่ใช้อยู่

## ข้อควรรู้เรื่องข้อมูล

- ข้อมูลอยู่ในเครื่องเท่านั้น ไม่ซิงก์ข้ามเครื่อง เปลี่ยนมือถือต้องย้ายด้วยไฟล์สำรอง
- ถอนการติดตั้งแอพ / ล้างข้อมูลเว็บไซต์ = ข้อมูลหาย
- กด **สำรองข้อมูล** ในแท็บ “รายการ” เป็นระยะ (ได้ไฟล์ `.json`) แล้วกด **กู้คืนข้อมูล** บนเครื่องใหม่
- เปิดแบบ `file://` (ดับเบิลคลิกไฟล์) จะใช้งานได้แต่ **ติดตั้งเป็นแอพไม่ได้** เพราะต้องเป็น https
